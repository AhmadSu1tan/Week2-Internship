# W2-PM5: Zenmap Based Network Scanning

## Objective
Understand network scanning and host discovery using
Zenmap and Nmap.

## Tool Information
- Zenmap Version: 7.991
- Nmap Version: 7.991
- Operating System: Kali Linux 2026.3

## Planned Activities
1. Understand Zenmap interface and scan profiles.
2. Identify local network interfaces.
3. Understand host discovery.
4. Perform an authorized local LAN ping scan.
5. Export scan results in XML and normal formats.
6. Analyze discovered hosts.

## Planned Scan Type
Nmap Ping Scan (-sn)

This scan discovers hosts without performing port scans.
