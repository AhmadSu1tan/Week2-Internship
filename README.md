# Week 2 Cybersecurity Internship

A practical cybersecurity portfolio documenting network scanning and passive OSINT using Kali Linux.

## Modules

### 01 - Network Scanning (Nmap / Zenmap)
- Authorized local network host discovery.
- Service and version detection against the Nmap Scanme testing host.
- Analysis of open, closed and filtered ports.
- Nmap, XML and Grepable scan evidence.

### 02 - Passive OSINT (theHarvester)
- theHarvester 4.11.1.
- CRT.sh certificate-transparency lookup.
- Controlled demonstration using example.com.
- XML and JSON evidence generation.

## Tools
- Kali Linux
- Nmap 7.991
- Zenmap 7.991
- theHarvester 4.11.1
- Git and GitHub CLI
